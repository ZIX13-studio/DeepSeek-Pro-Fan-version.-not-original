# Better DeepSeek — Black Icon Edition

A custom Android build of [Better DeepSeek](https://github.com/EdgeTypE/better-deepseek) with a black DeepSeek whale icon on a white background.

## Changes

- Replaced the launcher icon with a black-and-white DeepSeek icon.
- Left the original app name, interface, and functionality unchanged.
- Updated the version to **0.1.17**.

## Requirements

- Android **8.0 or later**.
- An internet connection.

## Installation

1. Download `Better-DeepSeek-0.1.17-black-icon.apk` from the release assets.
2. Open the APK on your Android device.
3. Allow installation from this source if prompted.
4. Complete the installation and launch the app.

## Build Notes

- This is a **debug-signed custom build**, not an official release.
- It can update the previous custom build signed with the same key.
- Other builds may have a different signature and cannot be updated with this APK.
- Back up your data before uninstalling an existing version.

The APK was built successfully and its signature was verified. It has **not been tested on a physical Android device**.
